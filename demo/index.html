5. Pre-deployment guard — own agents guarding the deployment

Before anything deploys, my own guardian agent runs every check, writes a developer report, and the remediation agent fixes what it safely can. High-risk fixes need a named human approval — they are never silently auto-deployed. This section runs the same code as the Node tests (core/guardian.js, core/remediation.js, core/predeploy.js).
