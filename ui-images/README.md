# Agentforce in Healthcare CRM — Prototype UI Images

Author: Rishi Gullapalli (rishisfdc9-daaku)

These are prototype screen mockups for the Agentforce in Healthcare CRM
project, matched to the screens in `../demo/index.html`. They are design
mockups, not screenshots of a live system, and all member/case data in
them is fictional mock data only. No real patient data is used.
No demo code was changed to make these images, and nothing here has
been uploaded to GitHub or LinkedIn — that attachment step is separate.
